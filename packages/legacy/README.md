# Deprecated: node-utils

> Previous generation of Node.js utilities and wrappers.

> [!IMPORTANT]
> Please use the newer version `@latest` if possible.

## Development

### NPM Publish

The previous or _legacy_ version remains at Version 3 (`v3`).

The newer versions are `v4` and higher.

Publishing this with the npm dist-tag `legacy` (the default npm dist-tag is `latest`).

```sh
npm publish --tag legacy --provenance false
```
